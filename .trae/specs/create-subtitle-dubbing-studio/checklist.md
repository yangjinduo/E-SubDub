# Checklist

## 资源管理
- [ ] 资源状态栏横向显示 5 项资源（音频提取/人声分离/音频转文字/文本校对与翻译/声音克隆），上方功能名、下方模型名
- [ ] 未就绪资源显示"需下载 XX，约 XX GB"与应用内下载按钮（含模型主页链接）
- [ ] 下载需弹窗选择位置、显示进度条、支持失败重试；魔搭为主源、HF 备选
- [ ] 已就绪资源显示文件位置与删除按钮，删除后回到未就绪
- [ ] LLM 支持 4B（默认）/1.7B/8B 档位切换

## 硬件检测
- [ ] NVIDIA 显卡自动启用 CUDA；Apple Silicon 自动启用 MPS；Intel Mac/无独显走 CPU 并标注"速度较慢"
- [ ] UI 显示当前推理设备

## 主界面
- [ ] 支持拖拽与点击选择导入视频/音频，显示文件信息
- [ ] 字幕设置：源语言、目标语言、字幕形式三选一（单语/双语目标在上/双语源在上）
- [ ] 配音开关默认开启；输出目录可设置
- [ ] 流程进度区显示步骤级进度与日志，审核暂停点可恢复继续

## 流水线
- [ ] 视频输入先提取 full_audio.wav；音频输入跳过提取
- [ ] Demucs 分离出 vocals.wav/no_vocals.wav；仅字幕模式默认跳过分离并提供进阶选项
- [ ] ASR 输出 [{spk, start, end, text}]；>90 分钟音频分段转写且跨段说话人标签全局一致
- [ ] LLM 校对保留原 start/end 时间戳；无用段落标记删除（置灰可恢复）而非物理删除
- [ ] LLM 翻译输出 [{spk, start, end, target_text}] 且译文长度受 end-start 时长约束
- [ ] TTS 优先原生时长控制生成；偏差用不变调 time-stretch 对齐；伸缩比 >1.3x 或 <0.7x 的句子进入异常复听
- [ ] 混音前 TTS 片段响度对齐原人声综合响度，再与 no_vocals 叠加
- [ ] SRT 按所选形式生成（单语/双语两种上下排列）
- [ ] MKV 封装：视频流 copy 不重编码、原音轨保留、新配音轨为默认音轨、SRT 为软字幕轨带语言标记

## 审核界面
- [ ] ASR 审核：文本可编辑、说话人下拉修改、片段试听、标记删除句置灰可恢复
- [ ] 说话人修改后该句 TTS 参考音色自动联动更换
- [ ] 每个说话人的参考音色片段可试听、可手动更换
- [ ] 译文审核：原文/译文对照可编辑，提供跳过开关；审核确认后才批量 TTS
- [ ] TTS 异常复听：超限句逐条试听、改译文重新生成

## 中间产物
- [ ] 输出目录下按导入文件名建文件夹存储中间产物
- [ ] manifest 记录各阶段状态；重复执行同文件任务自动跳过已完成阶段并复用产物
- [ ] 任务完成后弹窗询问"删除临时文件（保留成品）/ 留作备用"

## 模式与平台
- [ ] 仅字幕模式端到端可用：提取（可跳）→ ASR → 校对 → ASR 审核 → 翻译 → 译文审核 → SRT；源语言=目标语言时跳过翻译
- [ ] 配音模式端到端可用：全流程 → MKV 成品
- [ ] Windows 与 macOS 均可运行并打包分发
- [ ] 首次使用配音功能展示声音克隆使用授权提示
